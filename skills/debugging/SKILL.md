# Debugging Skill

1. Reproduce the failure reliably before attempting a fix.
2. Bisect: isolate the smallest change/input that triggers the bug.
3. Read error messages and stack traces fully before hypothesizing.
4. Add targeted logging/assertions rather than guessing.
5. Write a regression test once the root cause is found.
