# Web Research Skill

## When to use this skill
Any question needing current, external, or web-only information.

## Instructions
1. Formulate multiple targeted queries rather than one broad query.
2. Cross-check important facts across at least two independent sources.
3. Note publication dates; prefer recent sources for fast-moving topics
   (pricing, APIs, current events).
4. Summarize findings with links back to sources so claims are verifiable.
